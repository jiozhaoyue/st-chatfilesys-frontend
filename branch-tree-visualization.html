📖 概念术语

🏢 楼层（Floor）
聊天中的一条消息（用户消息一层、AI 回复一层，交替排列）。楼层编号全局统一，从 0 开始递增。楼层 3 就是楼层 3，不管哪个 branch，相同楼层号 = 相同"高度"。
📦 Swipe 组（Swipe Group）
一个楼层中的一个消息集合。一组 swipe 变体 + 对应元数据。每个 Swipe 组属于唯一一个 branch。
🌿 Branch（分支）
从某个分叉点 Swipe 组开始，到后续楼层的一组 Swipe 组路径。同一个"聊天家族"内可以有多个 branch。
🏘️ 聊天家族（Chat Family）
一组互为 branch 的聊天集合。现在 Luker 里一个角色的多个 jsonl 文件就是一个"聊天家族"。
↔️ Swipe（滑动）
一个 Swipe 组内的多个版本。只能在当前楼层内切换，不影响上下楼层。
🍴 分叉点（Fork Point）
一个楼层中，如果有多个 Swipe 组（分属不同 branch），这个楼层就是分叉点。切换 branch 必须回到分叉点。
🔄 切换 Branch
用户回到分叉点楼层，选择另一个 Swipe 组，然后顺着该 branch
