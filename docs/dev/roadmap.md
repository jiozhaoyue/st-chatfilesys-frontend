四期内已完成的部分（原作清单，逐条核对过）：

- 原生「创建分支 / 创建检查点」接管（点宿主原生按钮不再落复制文件，直接在库内成结构）
- 双写模式（库为准 + 磁盘保留标准聊天文件，只写不读）
- 入库提醒弹窗（四选择 + 冷启动也弹 + 两个压制勾选）
- 主分支可换（「设为主分支」；主分支不可直接删，要先换）
- 界面分工收敛（唯一界面 = 弹窗四页签；聊天界面只剩入口按钮与版本按钮）
- 每层版本按钮（仅该层 swipe 组数 > 1 时出现）+ 版本弹窗四项能力（预览 / 切换 / 多选删除 / 重排）
- 分支树上的自动编号、切换展开方向、AI 总结按钮
- 聊天记录零丢失（聊天头整份往返；其他插件写进去的东西不被抹掉）
- 两处以上同时改同一聊天的互相覆盖防护（版本号对不上就明确回冲突）

## 明确不做

| 项 | 理由 |
| --- | --- |
| 独立演示页 / 独立态视图 | 它既不是真实实例、也不产生实例没有的东西；界面验证一律在真实实例里做 |
| 加密磁盘上的 jsonl（默认形态） | 宿主自己要读 jsonl 才能渲染聊天——加密它等于聊天打不开 |
| 承诺「管理员完全看不到」 | 做不到：浏览器里的 JS 由服务器下发，且运行期明文有必经之路（见[隐私边界](/guide/privacy)） |
