## 两条读文档前要知道的纪律

1. **API 事实以官方文档为准。** 本项目的宿主是 SillyTavern / Luker；
   写调用宿主的代码时依据**官方文档**，**不通过阅读宿主源码去"发现" API 用法**。
   运行时行为可以用探针实测，但契约以文档为准。
2. **同一事实只允许一处权威表述。** 人向内容在 `docs/`（本站，会发布）；
   机向的编码细则在 `.trellis/spec`（**本仓不发布**）。
   两处**引用而非复制**——否则必然漂移。

> ⚠️ 口径提醒：本仓的 `.trellis/` 目录被 `.gitignore` 排除，
> 其中的规范与任务文档**只存在于开发者本机**。引用它们时**不得写成"已发布"**，
> 也不要从本站链接过去（那对别人是死链）。完整条文见[文档政策](/dev/docs-policy)。
