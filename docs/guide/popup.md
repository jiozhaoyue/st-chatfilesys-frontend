# 管理弹窗

## 它做什么

本插件的**唯一界面**。分支、模式、导入、回收站这些操作都在这里。

## 怎么用

### 打开

输入框上方**工具图标排**里的插件图标，或 `Alt+B`。

### 四个页签

| 页签 | 内容 |
| --- | --- |
| **当前聊天** | 当前聊天的分支结构与操作入口 |
| **角色卡的聊天** | 当前角色名下所有聊天/家族 |
| **设置** | 存储模式三选一、保存后自动导出、当前存储档位提示 |
| **回收站** | 列出 / 还原 / 立刻清理 |

### 界面纪律（这个插件刻意遵守的几条）

1. **唯一界面就是它**：扩展设置抽屉**零注入**（原生扩展设置区里没有本插件的配置项）。
2. **新增分支只走宿主原生入口**——插件**不做**任何"新建分支"按钮（见[原生创建分支/检查点接管](/guide/native-branch)）。
3. **绝不逐层列举楼层**：弹窗里任何位置都不会一行一行列出消息。
   曾经有过一个「楼层」页签，已删除，不再出现。
4. **结构树只显结构**：节点只显示序号 / 分支名 + 层数，**不含任何消息内容**。

### 聊天界面里有什么

只有**两样**，其余零插件元素（无徽章、无悬浮窗、无工具条）：

1. 上面说的**入口按钮**；
2. 消息旁的**版本按钮**——**仅当该层 swipe 组数 > 1 时**出现，
   形状是**分叉图标 + 计数**（如 `⎇ 2/3`）。**不用左右箭头**：箭头这个形状归宿主原生 swipe。

> `/cb` 斜杠命令**已删除**，请用按钮或 `Alt+B`。

## 边界与未做到

- 弹窗里的**容量/条目枚举能力按存储档位不同**：回收站只有**档 1（服务端数据库）**能列出条目，
  另两档弹窗里会**直说不可用**，不假装空列表。
- 弹窗**不提供**逐层查看消息的入口（有意为之，见上「界面纪律」第 3 条）。
- 关于「唯一界面」这一形态：这是**本插件经用户特批的例外**，
  其他插件仍应按「复杂 UI 用官方 Popup、设置放扩展设置抽屉」的通用规范执行。

## 失败与降级时的表现

- 弹窗打开时若库不可用，页面会显示当前档位与降级提示（如「当前仅本地缓存」），**不会静默空着**。
- 任何写操作失败都会给出**说明原因**的提示，而不是静默丢弃。
