### 四、有意不做

| 事项 | 理由 |
| --- | --- |
| 独立演示页 / 独立态视图 | 不是真实实例，也不产生实例没有的东西 |
| 默认形态下加密磁盘 jsonl | 宿主自己要读它才能渲染聊天 |

| 弹窗里逐层列举楼层 | 已废除的错误实现，不得重新引入 |

## 怎么用这张表

- 想确认"某个功能能不能用" → 看第一、二类。
- 想确认"我的隐私有没有保障" → 直接看[隐私边界](/guide/privacy)，**不要**指望第三类能绕开。
- 想知道"接下来会做什么" → 看[路线图](/dev/roadmap)。
