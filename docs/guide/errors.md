# 出错时你会看到什么

这一页说明本插件出错时的提示长什么样、怎么用它。

## 提示长什么样

出错不会只弹一句「操作失败」。弹窗顶部会出现一条错误条，每一条包含四样：

```
CFS-N004  结构图一个节点都没读到，但当前聊天是有内容的。
怎么办：点「重算」 / 确认存储模式（纯库模式下要先把聊天转库） / 复制诊断信息
▸ 为什么 / 原始信息
```

- **编号**（`CFS-…`）：每个编号对应一类问题，可以检索。**报问题时报这个编号就够了。**
- **一句话说发生了什么**：人话，不带内部函数名和堆栈。
- **怎么办**：可以直接做的下一步。
- **为什么 / 原始信息**：默认折叠。归因是**有证据才写**的——没有证据就写「未定位」，
  **不会编一个像模像样的原因**。原始错误文本也在这里，可以复制。

多条同时失败时会**聚合成一条**（「N 项失败」），不会刷屏。任何页签下都看得见。

## 两个按钮

- **复制诊断**：把全部失败连同编号、原因、原始信息，再加上扩展版本、存储模式、
  存储档位、宿主版本一起复制到剪贴板。出问题时把这整段贴出来。
- **清空**：把提示清掉。**它不动任何数据**，只是把提示收起来。

## 编号前缀的含义

| 前缀 | 哪一块 |
| --- | --- |
| `CFS-G…` | 通用 / 环境 |
| `CFS-S…` | 存储（切档、双写同步、未入库） |
| `CFS-I…` | 导入 / 转库 |
| `CFS-B…` | 分支（切换 / 改名 / 删除 / 设为主分支） |
| `CFS-M…` | 合并 |
| `CFS-V…` | 每层版本 / swipe |
| `CFS-R…` | 回收站 |
| `CFS-A…` | AI |
| `CFS-X…` | 导出 |
| `CFS-N…` | 结构图 |

## 几条「看着像坏了、其实是对的」

- **图是空的**：如果当前聊天确实没有内容，空图是对的。但**当前聊天有内容而图是空的**，
  插件会报 `CFS-N004` 说明「是没读到」而不是「没有」。
- **「这个聊天还没入库」**：纯库模式下，没转库的聊天不在库里，这是对的——
  去「当前聊天 → 转库」。
- **回收站显示「当前档位不支持枚举」**：只有第一档（Authority）能列目录。
  这不是「回收站空了」，插件不会假装它是空的。

## 报问题时给什么

1. 错误条上的**编号**
2. 点「复制诊断」得到的**整段文本**
3. 你刚才在做什么

有这三样，定位通常不需要再问第二轮。
