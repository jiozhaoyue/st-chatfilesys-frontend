# 分支树

## 它做什么

用一棵 **SVG 结构树**把家族的分支关系画出来，让你一眼看到**从哪里分叉、谁接谁**。

## 怎么用

- 在**管理弹窗**里查看。树可**缩放与平移**。
- 节点显示**序号 / 分支名 + 层数**。
- 带**自动编号**；自定义名附在序号之后。
- 可**切换展开方向**。
- 有 **AI 总结**按钮（手动点）。

## 边界与未做到

- **树只显结构，不含任何消息内容**。这是刻意的：节点是"哪条分支、多少层"，
  不是消息预览——消息内容请用宿主的原生界面看。
- **AI 总结按钮在没有可用的生成链路时不出现**（而不是点了报错或转圈）。
- 弹窗里**不会逐层列出楼层**——树是结构视图，不是消息列表。
  曾经有过一个逐层列举的「楼层」页签，属已废除的实现，不会在任何位置重新引入。
- 树的**渲染性能**在超大图上尚未做针对性优化（分支图的渲染与交互仍在进行中，
  见[图视图](/guide/graph)与[路线图](/dev/roadmap)）。

## 失败与降级时的表现

- 库不可用时打不开树，但**其他功能不受影响**（见[三档存储与降级](/guide/storage-tiers)）。
- 图数据缺失或投影不全时不抛异常，**能画多少画多少**。
