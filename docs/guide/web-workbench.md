# web 工作台（独立网页形态）

> 状态：2026-11-07 起提供；2026-11-08 起带阅读视图 / 全局搜索 / 统计概览 / 家族删除。与酒馆插件**同一套 core/ui**（三形态同构）——本页只写 web 形态的差异，通用能力看对应功能页。

## 它是什么

不装进酒馆、直接在浏览器里打开的独立页面：**UI 与插件弹窗完全一致**（同一份渲染代码），动作语义相同。定位：聊天记录的**查看 / 编辑 / 转换**。

- 本地打开（开发形态）：在本仓根目录运行 `npx --yes http-server . -p 3050 -a 127.0.0.1 -s --cors -c-1`，访问 `http://127.0.0.1:3050/web/index.html`
- 构建产物：`web/` 目录用 Vite 构建出 `dist-web/`（`base: './'`，可放任意静态目录）

## 阅读视图 / 搜索 / 统计（web 壳层能力）

顶栏「**阅读视图**」把当前分支铺成整篇对话（左右气泡 / 楼层号 / 时间 / 多版本角标），点任意一条打开该层版本管理：

- 工具栏可**换一条分支来读**（别的分支是只读投影——要编辑先点「切到此分支」落库切换）
- 「**导出 Markdown**」把正在读的分支存成人读文稿（只读快照，正文原样）
- 键盘：`←` / `→` 上一层 / 下一层，`Esc` 关闭阅读（输入框聚焦或有模态打开时让路）
- 「日期分隔线」：相邻消息日期不同时自动插一条
- **内联版本预览**：有 swipe 的楼层气泡底部出现「◀ 版本 N/M（预览）▶」，纯客户端翻看对照
  （预览不落库；正式切换 / 编辑仍走版本管理）
- 顶部细进度条显示阅读位置；字号（A－/A＋）记忆在浏览器本地
- 大家族实测：300 层导入 71ms、阅读视图整篇渲染约半秒、翻层即时

顶栏搜索框在**当前家族全部楼层正文**里搜（含其他分支的变体行），命中片段高亮，每条命中可「版本管理」（直接编辑）或「阅读定位」（滚到那条并高亮）。

搜索框下方一排统计徽章：分支数 / 活跃分支 / 全库楼层 / 多版本层 / 库行 / 字数 / 用户与角色占比 / 时间跨度（多版本层 = 库行数 ∪ 内联 swipe 数的口径，详见页面悬停说明）。

## 与插件的差异（如实）

| 能力 | web 形态 | 原因 |
| --- | --- | --- |
| 五页签 UI | **完全一致** | 同一模板源（`ui/popup.js`） |
| 分支管理 / 结构图 / 回收站 / 设置 | 可用 | 纯前端 + 存储适配器 |
| 每层版本（切换/删除/重排/编辑） | 可用（顶栏「版本管理」/ 阅读视图 / 搜索三个入口） | 同 `ui/versions.js` 内容，`<dialog>` 承载 |
| 导入 .jsonl / 导入为子分支 | 可用（顶栏导入；同文件有差异时询问合并） | 与插件同一条导入/合并路径 |
| 导出当前分支 / 导出 Markdown | 可用（标准 JSONL 下载 / 人读文稿） | — |
| 删除家族 / 家族改名 | 可用（顶栏「删除家族」确认对话框 /「改名」输入新名；idb 档可重新导入源文件重建） | 适配器契约 `deleteFamily` / `renameFamily`（2026-11-08 修复档3 删除的事务时序） |
| AI 总结 / 与库同步一次 | **置灰** | 需要酒馆运行时（生成链路 / 宿主文件通道） |
| 角色卡的聊天列表 | 空态说明 | web 无宿主文件面（接入酒馆直连后启用，未实现） |
| 消息旁版本按钮 / 接缝 | 不适用 | 无宿主消息流；版本入口在顶栏 |

## 数据存哪（事实源口径，如实）

- 默认后端 = **IndexedDB（缓存档）**：页面顶栏徽章会显示实际档位与降级链。
- **IndexedDB 只是本机缓存，不是事实源**（与插件同一条纪律）：换设备/清浏览器数据会丢。
  可带走的持久物 = 「导出当前分支」的标准 JSONL 与「导出 Markdown」文稿；完整备份/服务器事实源由后续版本接入。
- 重开页面回到上次打开的家族（记忆在浏览器本地）。

## 出错时你会看到什么

- 写入冲突（比如另一个标签页写过）：错误面出现「写入被拒绝（版本冲突）」条目，重新打开家族再试——不会覆盖别人的内容。
- 双击 `file://` 打开只有白屏：浏览器安全边界（ES 模块 CORS），页面会给出一句「该怎么办」的说明。
- 任何失败都进弹窗顶部错误面（编号 + 怎么办），不静默；漏网的页面级异常也会弹页内提示（不静默）。
