# 主分支

## 它做什么

一个家族可以有**多条分支**，其中一条是**主分支**——它代表"这个聊天本来的样子"。

## 怎么用

在管理弹窗里选一条分支，**设为「主分支」**。

## 边界与未做到

- **主分支不能直接删**：要先换一条别的分支当主分支，然后才能删原来那条。
  这道约束是为了避免"删完没有主分支"的悬空状态。
- **普通的分支切换也会迁主分支**——而且**只在主键上迁**（不会因为你在某个分支/检查点键上
  切来切去就把家族的主分支改掉）。
- 相关但不属本页的能力：**解绑重绑角色**、**聊天改名后的自动索引**
  （改名时的键对齐已做到，解绑重绑还没做，见[路线图](/dev/roadmap)）。

## 失败与降级时的表现

- 试图删主分支时**明确拒绝并说明要先换**，不静默忽略。
- 写入冲突（两处同时改）时按[并发写与冲突](/guide/concurrency)的规则回冲突，由酒馆重拉重写。
