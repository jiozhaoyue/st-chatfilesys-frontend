# 回收站

## 它做什么

存放**被移除的家族/导入源**，让你能**列出来、还原、或立刻清理**。

## 怎么用

在管理弹窗的**「回收站」页签**里：

| 操作 | 说明 |
| --- | --- |
| **列出** | 看回收站里有什么（来源、放入时间） |
| **还原** | 放回原处 |
| **立刻清理** | 真正删掉，不可恢复 |

## 边界与未做到

- ⚠️ **只有「档 1（服务端数据库）」能列出条目。** 另两档**没有枚举接口**，
  弹窗里会**直说不可用**，**不假装空列表**——空列表会让人误以为"回收站是空的"。
- **回收站是导入与删除的安全网**：[导入旅程](/guide/import)在**删源之前**必须先成功移进回收站。
  这条顺序反了就是不可逆的数据丢失。
- **「立刻清理」是不可逆的**（与"移入回收站"不同）。
- 「解绑重绑角色」等相邻能力见[路线图](/dev/roadmap)。

## 失败与降级时的表现

- 当前档位不支持枚举时，页面明确显示**不可用**，而不是显示空。
- 还原失败会**说明原因**（例如原位置已被占用），不会静默失败。
