# 安装与入口

## 它做什么

把 ChatFilesys 装进酒馆，并用它提供的两个入口打开界面。

ChatFilesys 是 **SillyTavern（及 Luker 分支）的第三方前端扩展**。它把「分支」从**整文件复制**
变成**聊天数据内的结构化组织**，并把超大的 jsonl 会话文件变成分片存储。

## 怎么用

### 安装

用酒馆自带的扩展安装器，填这个 Git 地址：

```
https://github.com/jiozhaoyue/st-chatfilesys-frontend
```

**装完即可用——不需要跑 `npm install`，也不需要构建。** 扩展目录里是可直接加载的源码
（浏览器原生 ES Module）。第三方库（如布局库 dagre）以本地副本形式随扩展分发。

### 两个入口

| 入口 | 位置 |
| --- | --- |
| 插件按钮 | 输入框**上方工具图标排**里的 ChatFilesys 图标 |
| 快捷键 | `Alt+B` |

两者打开的是**同一个管理弹窗**。

### 在哪里设置

在**弹窗的「设置」页签**里（存储模式三选一等）。
扩展**不注入自己的设置抽屉**——酒馆原生扩展设置区里没有 ChatFilesys 的配置项。

## 边界与未做到

- **界面只有一处**：整个插件只有管理弹窗这一个界面。聊天界面里只留两样东西——
  **入口按钮**与**版本按钮**（后者且**仅在该层的 swipe 组数 > 1 时**出现）。
- **不设独立演示页**：早期有过独立态页面与演示页，已按「无包袱铁律」移除。
  它既不是真实实例、也不产生实例没有的东西，界面验证一律在真实实例里做。
- 扩展**不修改酒馆核心**，也不改上游分发物。

## 失败与降级时的表现

- **后端不可用不影响主路径**：本插件的所有功能在**纯浏览器**下闭环可用。
  服务端能力（如 Authority 数据库档）只是**可选增强层**，不可用时沿存储降级链回退
  （见[三档存储与降级](/guide/storage-tiers)）。
- **装完不激活**：若页面无入口按钮，先确认扩展在酒馆的扩展列表里处于启用状态；
  宿主版本过低时扩展会在控制台留下归因到本插件的前缀日志（`[chatfilesys-*]`），
  而不是静默什么都不做。
