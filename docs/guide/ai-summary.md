# AI 总结

「当前聊天」页签里选中一条分支，点「AI 总结」，模型会给这条分支写一句概括，存在分支上。
概括会显示在结构树的节点上。

## 它怎么调模型

用**你在酒馆里当前选中的连接与预设**——本插件不自己配密钥、不另开连接。
所以「AI 总结没法用」几乎总是**连接或预设的问题**，不是插件的问题。

## 什么时候按钮不出现

两种情况按钮直接不出现（宁可不给，也不给一个点了没反应的）：

- 在设置里关掉了「启用 AI 功能」
- 当前宿主没有可用的生成链路

## 可以调的

设置页签的「AI」分组：

| 项 | 作用 |
| --- | --- |
| 启用 AI 功能 | 总开关 |
| AI：正文总字数上限 | 喂给模型的正文最多取多少字（默认 4000） |
| AI：每层截断字数 | 每一层最多取多少字（默认 200，避免一层长文挤掉后面所有层） |
| AI：摘要长度上限 | 生成的摘要最多保留多少字（默认 60） |

## 关于「推理型模型」

有些模型会**把思考过程一起吐出来**（形如 `…`）。插件的做法是：

- 把成对的思维块整段剥掉
- 把**不闭合**的半截标签也处理掉
- 剥完什么都不剩时，**如实说「生成结果为空」并拒绝写入**——而不是把残片当摘要在树上显示

## 失败时你会看到什么

- **「生成结果为空，未写入摘要」**：模型确实没给出可用内容。
  常见原因是预设给模型的输出预算被思考过程吃光了，或模型拒绝回答。**换一个模型或调高预算再试。**
- **`CFS-A001`**：生成链路不可用或调用被拒。错误条里带原因，点「复制诊断」可拿到全文。
- 插件的做法是**先试 `generateRaw`，不行再试 `generateQuietPrompt`**，
  并且**每次都校验返回值**。为什么要这样：实测发现有的宿主上
  `generateQuietPrompt` 会返回一个字符串化的 `undefined`（没真调用），
  若不校验就会把「undefined」写成摘要——**看起来还像成功了**。
