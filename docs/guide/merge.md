# 合并分支

把两条分支合成一条。**它不改原来那两条**——结果是一条**新分支**。

## 怎么用

「当前聊天」页签 → 分支管理 → 先在下拉里选中一条分支 → 点「合并…」。

弹窗里选「并入」的那一条，看它给出的规划，然后点「合并」。
只有一条分支时这个按钮是灰的（没有可合并的对象）。

## 它到底算了什么

逐层往下比：

- **开头相同的部分**：原样保留（两条分支在这里本来就是共享的，不是两份内容）
- **只有一边有的层**：保留有内容的那一边
- **两边都有、内容不同**：这是**冲突**，由你逐层选

冲突那一层会显示「用目标（多少字）/ 用另一条（多少字）」，各带一个「看」按钮，
点了才展开那一层的正文——**不点就不会显示内容**，弹窗不会被正文撑爆。

## 结果长什么样

- 是一条**新分支**，名字默认叫「合并·A+B」，可以改
- **原来两条一字未动**
- 所以**撤销就是删掉这条新分支**——没有任何历史被改写

## 边界与未做到

- **只搬引用，不复制内容**：合并只决定「这个位置用哪一份内容」，不会把正文复制成新的一份。
  想让某个版本独立出来，那是另一件事，不在合并里。
- **不自动切过去**：合并完成不会把你切到新分支——切分支会改变你正在看的聊天内容，
  那应该是你自己的决定。
- **冲突必须你选**：没选的冲突会按「目标分支」那一侧处理，并在规划里如实标出还有几处没定。
  插件不会替你猜哪边该留。
- **合并的是同一家族内的分支**：跨角色的聊天合并不在范围内。

## 出问题时

失败会在弹窗里当场显示（关掉弹窗就把错误也关掉了），并在管理弹窗顶部留下一条 `CFS-M001`。
两条原分支在任何失败情形下都不会被改动。
