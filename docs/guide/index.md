# 指南

面向**使用者**的功能文档。每个功能一页，每页四节：**它做什么 / 怎么用 / 边界与未做到 / 失败与降级时的表现**。

---

## 功能一览

下表是本扩展的功能面清单。每项都会有独立页面（正在补齐中；本页会在页面落地时逐项接上链接）。

| 功能面 | 一句话 |
| --- | --- |
| 安装与入口 | 装完即可用、无构建步骤；入口是输入框上方工具图标排的插件按钮 + `Alt+B` |
| 三种模式 | JSONL 增强 / 纯数据库 / 双写，在弹窗「设置」页签三选一 |
| 管理弹窗 | 唯一界面：当前聊天 / 角色卡的聊天 / 设置 / 回收站 四页签 |
| 分支树 | SVG 图形化结构树，只显结构不显消息内容 |
| 每层版本 | 消息旁的版本按钮（仅该层 swipe 组数 > 1 时出现）+ 版本弹窗四项能力 |
| 接管原生创建分支/检查点 | 点宿主原生按钮不再落复制文件，直接在库内成结构 |
| 导入旅程 | 把既有聊天收进库：智能合并 + 回收站 |
| 回收站 | 列出 / 还原 / 立刻清理 |
| 导出 | 单条分支导出、家族压缩包、自动导出 |
| 三档存储与降级 | Authority SQL → 官方通道 → IndexedDB 的自动选档 |
| 图视图 | 分支图的渲染与交互（进行中） |
| 隐私边界 | 哪些能保护、哪些**做不到**（如实写） |

---

## 怎么读这些文档

- 想**用**这个扩展 → 从「安装与入口」开始。
- 想**搞清楚数据存在哪** → 「三种模式」与「三档存储」两页。
- 想知道**它做不到什么** → 每页的「边界与未做到」一节；以及
  [纯数据库模式说明（人话版）](/pure-db-mode-explained) 末节的那张对账表。

> 术语说明：本仓统一用**分支**（branch）、**swipe**、**swipe 组**。
> 「swipe」= 宿主原生左右箭头所切的东西（同一条消息的多次生成变体）；
> 「swipe 组」= 某楼层的一份内容，**该层 swipe 组数 > 1 = 该层就是分叉点**。
