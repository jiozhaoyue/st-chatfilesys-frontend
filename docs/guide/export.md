# 导出

> **状态：部分完成。** 已能"把当前分支写成标准文件"，但**下载产物与家族压缩包还没做到**。

## 它做什么

把库里的内容**导出成纯标准 JSONL** —— 原生酒馆能直接打开的那种聊天文件。
**不引入任何私有格式**，这是本插件的一条硬承诺。

这与[双写模式](/guide/modes)的落盘不是一回事：
双写是**持续**写一份副本；导出是**你要的时候**产出产物。两者产出物都是标准文件。

## 怎么用

| 能力 | 状态 |
| --- | --- |
| 把**当前分支**写成标准文件（服务端动作） | ✅ 已有 |
| **下载**产出的文件到本地 | ⬜ 还没做到 |
| **整个家族**的压缩包 | ⬜ 还没做到 |
| 「保存后**自动导出**」开关（在弹窗「设置」页签） | ✅ 已有 |

## 边界与未做到

- **家族压缩包未实现**：一条家族里有多条分支，把它们打包成一份产物还没做。
- **下载链路未实现**：文件在服务端产出，把它取到本地还没做。
- 导出是**纯标准 JSONL**：不含本插件的私有字段形态，
  所以导出物**不依赖本插件**也能被酒馆打开。
- 从库出去的正文是**库里的事实**，不是磁盘副本的内容——两者可能不同（双写是滞后快照）。

## 失败与降级时的表现

- 导出动作失败会**说明原因**，不会产出半截文件冒充成功。
- 切换模式时会**先写文件再切**（写失败就不切），这条保障与导出同源（见[三种模式](/guide/modes)）。
