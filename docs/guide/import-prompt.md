# 入库提醒弹窗

## 它做什么

当你打开一个**还没收进库**的聊天时，提醒你可以把它收进去。

## 怎么用

- 打开未入库的聊天 → 弹窗出现（**冷启动也会弹**，不只在切换聊天时）。
- 弹窗给**四个选择**（收进去 / 保持原样等），以及**两个压制勾选**——不想再被提醒就勾上。
- 弹窗的关闭方式：右上角的 **X 是本插件自己画的**（在插件自己注入的弹窗内容里），
  不去和宿主的弹窗结构对抗。

## 边界与未做到

- 这是**提醒**，不是自动收编：**不会替你做决定**。不点收进去，聊天就保持在原样。
- 勾了压制之后**不再弹**（这是你的选择，插件不反复打扰）。
- 「智能合并」的细节见[导入旅程](/guide/import)——同名/同内容的重复不会被重复收进去。

## 失败与降级时的表现

- 库不可用时**不弹**（没有库可收，弹了也没用），而不是弹了之后报错。
- 收编失败会**说明原因**，不会静默消失。
